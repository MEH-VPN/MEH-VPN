# چک‌لیست انتشار نسخه (Release Checklist)

قبل از اینکه نسخه‌ای تگ و منتشر بشه، این موارد رو با APK تستی (ساخته‌شده با workflow_dispatch) روی گوشی چک کن. همه باید سبز بشن؛ اگه یکی قرمز شد، تگ نزن و گزارش بده.

1. APK تستی رو از بخش Actions (آرتیفکت ران dispatch) دانلود و نصب کن.
2. اپ رو باز کن و وصل شو — باید حداکثر تو ۳۰ ثانیه وصل بشه (زمان رو یادداشت کن).
3. یه سایت فیلترشده رو باز کن و مطمئن شو IP عوض شده.
4. قطع کن و دوباره وصل شو — باید دوباره وصل بشه.
5. اپ رو کامل ببند و دوباره باز کن — سرورهای ذخیره‌شده اول پیشنهاد بشن.
6. مطمئن شو نسخه‌ی نمایش‌داده‌شده تو اپ همون نسخه‌ی تستی باشه.
7. اگه همه سبز بود: تگ بزن، اعلام کن و تو کانال پست کن. اگه نه: تگ نزن.

روند انتشار: بیلد تستی ← تست روی گوشی با این چک‌لیست ← تگ ← اعلام آپدیت ← پست کانال.
